# Помощник Филармонии Кузбасса (kemfil-assistant)

Окно-чат на компьютере, где помощник отвечает на вопросы зрителей о концертах,
билетах и посещении филармонии. Ответы он берёт из базы, собранной с сайта
https://www.kemfil.ru. Устройство — RAG («найти, потом ответить»): поиск по базе
на Haystack + Ollama (модель bge-m3), ответ пишет ГигаЧат (или локальная модель gemma3:4b).

Учебный итоговый проект курса по промпт-инжинирингу.

## Структура проекта

```
kemfil-assistant/
  run_assistant.bat        ← главное: открывает окно чата с помощником
  update_afisha.bat        ← собирает свежую афишу с kemfil.ru и обновляет поиск
  prepare_github.bat       ← готовит чистую копию проекта для GitHub (без ключей)
  README.md                ← этот файл

  rules/                   ← КАК ПОМОЩНИК ГОВОРИТ (правится в Блокноте, действует сразу)
     system_prompt.txt        инструкция для модели: тон, точность, куда направлять
     clarifying_questions.txt уточняющие вопросы (возраст ребёнка, музыка, даты…)
     answer_example.txt       образец ответа — модель перенимает из него манеру
     ready_replies.txt        готовые ответы без модели: приветствие, грубость, отзывы…
     help_phones.txt          телефоны помощи для человека, которому плохо
     collective_aliases.txt   сокращения коллективов: ГЭДО, ГОРНИ, ГСО, СибКал…

  keys/                    ← СЕКРЕТНАЯ ПАПКА: ключ ГигаЧата и сертификат Минцифры
  data/                    ← база: concerts/, info/, collectives/, index.json, people.json, журналы
  docs/                    ← текст защиты проекта и скриншоты окна

  app/                     ← программы помощника
     okno.py                  окно чата (flet): разговор, защита от спама, выбор модели
     pomoshnik.py             поиск по базе и ответ модели; НАСТРОЙКИ МОДЕЛЕЙ
     pravila.py               чтение папки rules
     gigachat_api.py          подключение ГигаЧата
     maty.py, krizis.py       распознавание мата и тревожных сообщений
     dlya_github.py           чистая копия для GitHub
     requirements.txt         список библиотек
     assets/logo.png          логотип филармонии (шапка окна)
  collector/               ← программы, которые собирают афишу
     sborshik.py              сборщик афиши и страниц kemfil.ru
     indeksator.py            «библиотекарь»: готовит собранное к поиску
```

Служебная папка `.venv` (библиотеки Python) скрыта — её не трогайте.

## Как пользоваться

1. Запустите **Ollama** (она нужна всегда: через неё идёт поиск по базе).
2. Дважды щёлкните **`run_assistant.bat`**. Через 5–10 секунд появится приветствие.
3. Пишите вопрос и нажимайте Enter. Под каждым ответом видно, какая модель отвечала и сколько секунд.
4. **«Кто отвечает»** (список вверху) — смена модели прямо во время разговора.
5. **«Новый разговор»** — очистить чат и память помощника.

**Демо-режим для показа:** окно само меняет модель и задаёт вопросы —
`.venv\Scripts\python.exe app\okno.py --model "ollama|gemma3:4b" --demo "Куда сходить в субботу?" "Когда концерты ГЭДО?"`
(оба параметра необязательны).

Если помощник не ответил, в окне появится жёлтая подсказка для сотрудника: что случилось
и что сделать (чаще всего — запустить Ollama).

## Папка rules — поведение помощника

Все файлы открываются Блокнотом. Строки, которые начинаются с `#`, — пояснения, модель их
не видит. **Правки действуют сразу**, со следующего сообщения.

- **`system_prompt.txt`** — как помощник говорит (спокойно и тепло, без восторгов и «продавецких»
  слов), как ведёт разговор (отвечает на последнее сообщение, не повторяется, не поучает,
  при жалобах извиняется, при плохом самочувствии сначала помогает), куда направлять людей
  (касса, концертный отдел, приёмная) и правила точности.
- **`clarifying_questions.txt`** — какие уточняющие вопросы можно задать и когда (не больше
  одного за раз и только если ответ изменит совет).
- **`answer_example.txt`** — образец ответа на вымышленных событиях: модели проще подражать
  примеру, чем помнить запреты.
- **`ready_replies.txt`** — ответы, которые программа даёт сама, без модели (быстро, бесплатно
  и всегда одинаково). Впишите в раздел [где туалет], где туалеты на самом деле.
- **`help_phones.txt`** — **проверьте номера** и добавьте телефон доверия Кузбасса.

### Что программа делает сама (модель не может это нарушить)

- **Возраст цифрами** («ребёнку 5 лет», «нам 2 и 7 лет») — модель видит только события
  с маркировкой не больше возраста самого младшего.
- **Только концерты филармонии**: Большой, Органный, Камерный залы и Центральное фойе
  (список — `HOME_HALLS` в `app\pomoshnik.py`). Выездные — только если зритель назвал свой
  город («я из Юрги»). Концерты в школах — никогда. Отменённые и перенесённые не советуются.
- **Без приглашённых коллективов**: концерты с пометкой «Событие обслуживает звукорежиссёр
  приглашенного коллектива» сборщик не собирает (`SKIP_IF_TEXT` в `collector\sborshik.py`).
- **Готовые ответы без модели**: даты, когда концертов нет («какой концерт сегодня?») —
  и три ближайших; даты позже загруженной афиши; «где туалет»; выступить у нас, аренда зала,
  заказ съёмки — концертный отдел; впечатления и жалобы — страница отзывов
  https://www.kemfil.ru/reviews; тревожные сообщения; мат (после 3 раз помощник замолкает).
- **Коллективы и их сокращения** («когда концерты ГЭДО?», «Сипкал выступает?») — программа
  находит коллектив по `rules\collective_aliases.txt` и даёт модели все его ближайшие концерты.
- **Артисты из состава коллективов** («когда играет Ирина Прокопчук?», «есть ли Забавин в спектаклях
  „Слова“?») — сборщик читает вкладку «Состав» на страницах коллективов; у человека хранятся все его
  должности. Состав конкретного спектакля на сайте не публикуется — помощник так и говорит и
  отправляет в кассу, а не отвечает «да» или «нет».
- **Вопросы о самой филармонии** («только переехал, что это за место?», «репертуарная политика») —
  модель получает краткую справку со страниц «История», «Залы», «Музей», «Орган», «Проекты».
- **Праздники** («концерты ко Дню Победы?») — если праздник позже загруженной афиши, готовый ответ
  «афиша пока не загружена».
- **Уточняющий вопрос**: если модель не спросила возраст ребёнка или дни, а без этого совет неточен,
  программа добавляет один вопрос из `rules/clarifying_questions.txt`.
- **Выдуманные события**: строки, где предложен концерт, которого нет в базе, программа удаляет.
- **Смена темы**: если зритель перешёл к другому вопросу, поиск идёт только по новому вопросу.
- **Ссылки на билеты** сверяются с базой (название, дата, время, зал) и подставляются, если
  модель их потеряла.
- **Чистка ответа**: убираются «Дорогой друг», «Какой вариант Вам ближе?», заглушки вроде «[даты]».
- **Фильтр «чувствительных тем» ГигаЧата.** На любой вопрос о СВО ГигаЧат не отвечает, поэтому
  программа отвечает готовым текстом `[участникам СВО]` из `rules/ready_replies.txt` (взят со страницы
  сайта — если условия изменятся, поправьте его). Фильтр срабатывает и на слова в справке (например,
  «Донбасс» в описании концерта): тогда программа повторяет запрос без таких фраз. Если ГигаЧат
  отказал и второй раз, отвечает gemma3:4b — под ответом в окне это написано, а в журнале остаётся запись.
- **Защита от спама** (начало `app\okno.py`): не больше 6 сообщений в минуту, сообщение не
  длиннее 1000 знаков, повтор вопроса — без нового обращения к модели, не больше 60 обращений
  к модели в час.
- **Журнал окна** `data\app_log.txt` сам себя очищает: при 2000 записей остаются последние 1000.

## Модели

Модель по умолчанию — в начале `app\pomoshnik.py` (`CHAT_PROVIDER`, сейчас `"gigachat"`).

| Вариант | Плюсы | Минусы |
|---|---|---|
| **ГигаЧат** GigaChat-2 — основная | 1–4 сек., грамотно, серверы в России, бесплатный объём для физлиц | нужен интернет и ключ; вопросы уходят в Сбер |
| GigaChat-2-Pro | заметно лучше тон и точность | бесплатного объёма меньше |
| **gemma3:4b** (Ollama) — запасная | без интернета, данные не уходят с компьютера | маленькая модель, бывает неточна |
| DeepSeek | грамотный | платно, из России не оплатить российской картой; вопросы уходят за рубеж |

Перед тем как давать зрителям модель «через интернет», согласуйте это с юристом филармонии.

### Как подключить ГигаЧат

1. На https://developers.sber.ru создайте проект **GigaChat API** и скопируйте **«Ключ авторизации»**.
2. Откройте `keys\gigachat_key.txt` Блокнотом и вставьте ключ в пустую строку под пояснениями.
3. Сертификат Минцифры уже лежит в `keys` (с официальной страницы https://www.gosuslugi.ru/crt).
4. Проверка: `.venv\Scripts\python.exe app\gigachat_api.py` — покажет модели и пробный ответ.

## Обновление афиши

Дважды щёлкните **`update_afisha.bat`**: сборщик соберёт концерты и страницы (5–10 минут),
«библиотекарь» обновит индекс (~1 минута). Затем откройте окно заново.
Сборщик берёт концерты по 31.12.2026 (`COLLECT_UNTIL` в `collector\sborshik.py`), ходит
только по kemfil.ru с паузой не меньше 1 секунды и называет файлы латиницей.
Обновить только страницы и составы коллективов, не трогая афишу (≈ 1 минута):
`.venv\Scripts\python.exe collector\sborshik.py --bez-afishi`, затем `.venv\Scripts\python.exe collector\indeksator.py`.

## Выкладка на GitHub

Дважды щёлкните **`prepare_github.bat`**: рядом появится папка **`kemfil-assistant`** —
копия без ключей, журналов и `.venv`. Программа проверяет каждый файл копии и, если найдёт
настоящий ключ, удаляет копию и сообщает, где он. Выкладывайте именно эту папку.

## Установка с нуля

1. Python 3.10+ (https://www.python.org, галочка «Add python.exe to PATH»).
2. В PowerShell в папке проекта:
   ```
   python -m venv .venv
   .venv\Scripts\python.exe -m pip install -r app\requirements.txt
   ```
3. Ollama (https://ollama.com): `ollama pull bge-m3` и `ollama pull gemma3:4b`.
4. Ключ ГигаЧата — в `keys\gigachat_key.txt`; сертификат — `keys\russian_trusted_root_ca.cer`.
5. `update_afisha.bat`, затем `run_assistant.bat`.

## Если что-то не работает

- **«Простите, у меня сейчас не получается ответить»** — не запущена или зависла Ollama.
- **Не подключается ГигаЧат** — окно напишет причину; подробности — в `data\app_log.txt`.
- **Помощник ответил неверно** — проверьте, есть ли нужное в `data` (может, пора обновить
  афишу), и поправьте правила в `rules`.
